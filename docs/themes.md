# 浅色 / 深色配色

## 目标

阅读优先，避免纯黑底配刺眼白字、偏黄代码底以及低对比度深蓝选区。浅色采用纸白/墨灰，深色采用石墨灰/冷白；蓝色主要用于文本选区、焦点和交互强调。配色本身不改变文档、选区范围或历史；后续紧凑布局调整见[编辑器契约](editor.md)。

## 基础色板

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 正文背景 | `#FCFDFE` | `#181E28` |
| 标题栏/工具栏/标签背景 | `#F0F3F8` | `#202835` |
| 弹窗/按钮表面 | `#FFFFFF` | `#252F3E` |
| 次级表面 | `#E8EDF5` | `#2B3748` |
| 正文/UI 文字 | `#202B3C` | `#E5EAF2` |
| 次级 UI 文字 | `#43536B` | `#CADCF3` |
| 边框 | `#C6D0DE` | `#3D4D63` |
| 主操作/焦点 | `#245DA8` | `#A6CAFA` |
| 文本选区 | `#A6CAFA` | `#365F8D` |
| 菜单/列表激活 | `#D8E6FA` | `#2C4464` |

色值与映射集中在 `src/theme_palette.rs`。全局通过 Kit `Theme::update` 应用：控件 legacy tokens、Base semantic tokens 和所有窗口均由 Kit 自身同步。标题栏、状态栏、标签、按钮、表单、列表、菜单、弹窗、滚动条、表格、成功/警告/错误反馈共用角色，不在各页面散落临时硬编码。

## 选区与正文

- 原生文本选择使用明确的实色蓝底，保留原文字色；主正文/标题、引用、链接和代码的新版默认色都纳入选区文字对比度计算。
- 文本背景装饰绘制在字形后方；图片/行内原子装饰则绘制在内容上方，因此只对原子使用 40% 透明叠色，避免蓝块遮住图片。不改变原生选择或复制范围。
- `theme::document_style` 通过新增的上游 `BlockEditor::text_style` 接缝，把正文、标题、链接、引用、代码和表格表头接入当前主题。原先只设置 syntax-highlighter 不足以更新渲染正文，这次不再把二者混为一谈。
- 行号栏使用正文背景，保留 55% border 的细分隔线；普通数字为 80% muted，当前行号用 foreground 提亮，不再用蓝色或方块。固定宽度、满高背景和原生几何不变。
- 光标和输入法下划线采用主题焦点色。主题更新只重绘样式，不推进文档 revision，不清空历史或重建正文。

## 配置兼容

`MdColors` 保留原字段和文件格式。只有整个浅色/深色方案分别与旧出厂默认值完全一致时，加载时才升级为新版默认；改过任何字段的方案保持原样。不在本次源码操作中修改用户磁盘配置。

设置 → Markdown 颜色 → “恢复新版默认配色”只更新设置草稿内的颜色选择器，点击应用后才保存。选区和 UI 状态由统一主题管理，不混用代码背景。用户自定义色仍可破坏对比度，数值保障仅适用于新版默认值，不宣称任意颜色组合都可读。

## 默认色值数值检查

按 WCAG sRGB 相对亮度公式直接计算当前源码色值（非应用测试）：

| 组合 | 浅色 | 深色 |
| --- | ---: | ---: |
| 正文 / 正文背景 | 14.01:1 | 13.85:1 |
| 正文 / 文本选区 | 8.46:1 | 5.47:1 |
| 次级 UI 文字 / 文本选区 | 4.63:1 | 4.73:1 |
| 默认正文/标题/粗体/斜体/引用/链接/代码/语法文字中，选区上的最低值 | 4.62:1 | 4.94:1 |

这不包括用户自定义颜色、任意代码语言高亮、图片内容及显示器差异；原生渲染顺序与最终观感仍需打包后的用户验收。
